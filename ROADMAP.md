# Roadmap

This roadmap keeps the public edition focused on backend verification patterns while staying synthetic and safe to publish.

## Near Term

- Add profile-based demo runs, so command arguments can be captured in a reviewed YAML profile.
- Add an HTML summary report for demo artifacts.
- Add JSON Schema files for manifests, events, and reconciliation reports.
- Add a richer failure demo that intentionally produces replay and reconciliation failures.

## Medium Term

- Add plugin-style risk policy examples.
- Add snapshot export and import for replay state.
- Add artifact comparison across two runs.
- Add optional Markdown report generation.

## Out Of Scope

- Real exchange adapters.
- Real trading strategies or parameters.
- Production deployment scripts.
- Real account, order, position, or balance data.
- Private hostnames, credentials, or environment-specific configuration.
