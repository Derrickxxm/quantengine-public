# Changelog

## 0.4.0

- Reframed the project as evidence-controlled AI software delivery, with
  QuantEngine retained as the first runnable reference scenario.
- Added Architecture, Test, Development, and Ops Skill contracts plus a
  14-artifact Native Agent delivery Golden Path.
- Added request-bound fingerprints, typed producer and dependency checks,
  fail-closed gates, bounded release authority, and nine committed negative
  receipts.
- Enforced the runtime evidence -> QCS -> independent Quality Shield -> release
  controller order so failed or missing runtime evidence cannot receive PASS.
- Documented dynamic context assembly, one-Agent-first decomposition, explicit
  handoffs and independent review, and the failure-to-regression learning
  flywheel.
- Added public CI execution and upload of the generated Golden Path evidence.

## 0.3.0

- Added independent Paper and Replay implementations for the public v2 demo.
- Added tamper-evident package verification and negative tests for changed, missing, and extra files.
- Derived Paper authority from admission, package verification, reconciliation, and stress checks.
- Added committed synthetic showcase evidence and a 60-second GitHub walkthrough.
- Added public safety scan and calibrated README claims.

## 0.1.0

- Initial public edition MVP.
- Added synthetic replay, order lifecycle validation, risk policy checks, reconciliation, artifact manifests, release gates, CLI commands, tests, and CI.
